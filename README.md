# Student Management System

A simple Java-based Student Management System developed using Core Java, JDBC, and MySQL.

## Features

- Student Registration
- Course Registration
- Course Enrollment
- Attendance Management
- Marks Entry
- View Student Result
- View All Students
- Update Student
- Delete Student
- Transaction Management

## Technologies Used

- Java
- JDBC
- MySQL
- Eclipse IDE

## Database

Database Name:

student_management

### Tables

- students
- courses
- enrollments
- attendance
- marks

## Concepts Used

- Classes and Objects
- JDBC
- MySQL
- SQL
- CRUD Operations
- PreparedStatement
- JOIN
- Transactions
- Exception Handling
- Scanner

## How to Run

1. Install Java and MySQL.
2. Create the `student_management` database.
3. Create the required tables.
4. Add MySQL Connector/J to the project.
5. Update the MySQL username and password in the Java code.
6. Run `Main.java` as a Java Application.
